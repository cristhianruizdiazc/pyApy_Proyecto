# Registro de decisiones de arquitectura

No hay ADR de produccion aprobados. Las restricciones y autorizaciones conocidas estan en [DECISIONS.md](../DECISIONS.md).

En Fase 1, tras autorizacion, registrar las decisiones que se adopten usando archivos `ADR-NNN-tema.md`. Cada documento debe incluir estado, contexto, opciones, decision, razones y consecuencias. No presentar una propuesta como una decision aprobada ni inventar decisiones anteriores.
